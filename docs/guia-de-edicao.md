# Guia de edição

> **Ainda não disponível.** O painel de administração é criado na fase 3.
> Este guia será escrito para quem gere a loja, sem termos técnicos.

Vai explicar:

- Como entrar em `/admin`
- Como adicionar um artigo novo (nome, descrição, preço, tamanhos, categoria, fotografias)
- Como marcar um artigo como esgotado
- Como esconder um artigo sem o apagar (rascunho)
- Como mudar a ordem dos artigos
- Quanto tempo demora até a alteração aparecer no site (cerca de um minuto)
- Como desfazer uma alteração

## Entretanto

Enquanto o painel não existe, um artigo é um ficheiro Markdown em
`src/content/products/`. Os campos disponíveis estão definidos e comentados em
`src/content.config.ts`.
